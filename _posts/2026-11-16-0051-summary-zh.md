**「背景」** Fireworks AI 是提供大模型推理 API 服务的平台，Claude Code 是 Anthropic 推出的 AI 编程工具，可通过扩展集成进开发者编辑器。AI 编程工具的运行依赖 API 密钥与扩展分发渠道，这两个环节都可能成为供应链攻击的切入点——密钥被盗后可被用于支撑恶意工具的运行，使其看起来像正常服务。
