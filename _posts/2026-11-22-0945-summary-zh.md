<summary><strong>mod_wsgi 作者推出 Rust 编写的 Python 应用服务器 Muru ⭐️ 7.0/10</strong></summary>

拥有 20 年历史的 mod\_wsgi 的作者 Graham Dumpleton 推出了全新项目 Muru：一个用 Rust 编写、同时支持 ASGI 和 WSGI 的 Python 应用服务器，目标覆盖开发与生产两种环境，代码已托管于 GitHub（muruhq/muru）。自 2026 年 11 月 4 日起，他在三周内连续发表了 18 篇极其详尽的开发日志，内容涵盖 worker 内部机制、一次导入多次 fork、开发环境 HTTPS、WSGI 与 ASGI 混合运行、以发布替代重启、无需服务网格的金丝雀部署、Kubernetes 协作、基于 worker 反馈的自动伸缩、缩容到零以及页面级调试工具栏与 tracing 等。项目目前仍处于早期开发阶段，尚未发布稳定版本；Dumpleton 明确表示会持续打磨，直到它成为他自己也敢于信赖的产品。

rss · Simon Willison · 11月21日 23:56

**「背景」** mod\_wsgi 是 Dumpleton 约在 2005–2006 年间创建的 Apache 模块，长期是 Python Web 应用部署的主流方案之一；他此后一直在思考生产环境中服务 Python 应用的理想方式，Muru 正是这一思路的延续。与他此前开发 wrapture 时一样，他选择把详尽的开发过程公之于众，将连载写作本身作为开发流程的一部分。

**「影响」** 对负责 Python Web 部署的开发者和运维人员而言，Muru 的设计思路值得跟踪：它试图将灰度发布、自动伸缩、缩容到零和调试工具栏等通常依赖外部组件的能力直接内置到应用服务器中，并统一开发与生产体验。但由于项目公开仅三周、尚无稳定版本，生产环境用户目前应将其作为评估对象而非现有部署方案的替代品。

<summary><strong>群联展示内置 NPU 与 64GB 内存的 AI 推理固态硬盘 ⭐️ 7.0/10</strong></summary>

据 IT 之家转引 Tom's Hardware 报道，群联在 SC26 大会展示了两款面向 AI 场景的企业级 SSD。其中一款内置 NPU 与 64GB 内存，带宽 130GB/s，可直接在硬盘上运行 PyTorch、vLLM、OpenVINO 和 llama.cpp 等框架与推理工具；其设计思路是将部分计算从服务器转移到 SSD，设备就地处理存储数据并仅向主机返回结果，群联宣称特定工作负载下可减少 10 至 100 倍数据传输量并降低主机 CPU 负载。另一款采用 Mixed Media 混合介质设计，将 pSLC 缓存与大容量 QLC 闪存整合于同一 SSD，由 16 通道主控管理，两个存储区域分配独立命名空间，主机可按数据类型选择而无需专用软件；群联称在 24 块 SSD 的系统中单盘故障仅损失 4% 缓存，而传统 4 块独立缓存盘方案可能损失 25%。两款产品目前处于展示阶段，10-100 倍等数据为厂商宣称，实际性能与生态成熟度尚未经独立验证。

rss · IT之家 · 11月22日 00:04

**「背景」** 这类产品属于“计算型存储/近存计算”方向：随着 AI 推理需要反复读取大规模数据集，存储与主机之间的数据搬运逐渐成为瓶颈，厂商因此尝试把计算能力直接放进 SSD，使数据尽量就地处理。SC26 是存储行业的展示场合，混合介质设计则是另一条并行思路——通过把部分 QLC 闪存切换为 SLC 工作模式，以牺牲容量换取写入性能与耐久性，从而在同一块硬盘内同时承担缓存与大容量存储两种角色。

**「影响」** 对 AI 系统架构而言，若近存推理方案能够兑现，依赖大模型权重或检索数据集的推理工作负载可显著减少跨 PCIe 的数据搬运，从而降低主机 CPU 与内存的压力；但当前仍是展示阶段，企业用户在评估时需要关注框架兼容性、可编程性以及群联宣称数据的可复现性。混合介质方案则为缓存盘架构提供了替代路径：运维上可减少独立缓存盘数量并降低单点故障导致的缓存损失，代价是牺牲部分 QLC 存储容量，实际写入寿命与性能表现仍需实测验证。

**标签**: `#computational-storage`, `#AI-inference`, `#SSD`, `#enterprise-hardware`, `#near-data-processing`

rss · IT之家 · 11月21日 23:28

**「背景」** Signal 是一款开源端到端加密聊天应用，其加密机制保护消息在传输与存储环节不被读取，但系统级 AI 智能体可以在应用运行时读取屏幕显示内容，构成应用层隐私机制之外的读取路径。Signal 总裁 Meredith Whittaker 表示，系统级 AI 智能体影响力不断扩大，可能在用户毫不知情的情况下访问私人对话，对 Signal 长期建立的隐私机制构成威胁。

rss · IT之家 · 11月21日 13:16

**「背景」** 欧洲近期接连发生多轮针对超市制冷系统的网络攻击，导致数百家门店数吨食品变质，损失达数百万英镑。外界此前认为英国因制冷行业采用不同类型设备而基本避开此类攻击，但实际上英国同样存在一个潜在漏洞，业界一直在加紧修补。
